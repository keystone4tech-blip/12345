## Дата: 2026-05-02 (Продолжение)
### Изменения:
- Обновлен `bot/app/handlers/admin/pricing.py` для синхронизации цен с дефолтным тарифом в режиме `tariffs`. Теперь при изменении цены периода через админку Telegram она будет обновляться и у пользователей.
- Внесены правки в `bot/app/services/system_settings_service.py`: теперь **абсолютно все** настройки, изменяемые администратором через интерфейс бота (цены, вебхуки, реферальная программа и любые другие), будут иметь безусловный приоритет и сохраняться в базу данных, игнорируя значения, прописанные в `.env` файле. Раньше изменения многих настроек тихо блокировались.
- Обновлен `bot/app/webapi/routes/health.py`: маршрут `/health` сделан публичным (убрана проверка `require_api_token`), и добавлена поддержка метода `HEAD` (так как Docker healthcheck с `wget --spider` отправляет именно `HEAD` запрос), чтобы Docker мог успешно проверять статус контейнера без получения ошибки `401 Unauthorized` или `405 Method Not Allowed`.
- Улучшена рассылка стартовых уведомлений (`bot/app/services/startup_notification_service.py`): теперь сообщения об успешном запуске или падении бота отправляются всем администраторам напрямую в личные сообщения (взятые из `ADMIN_IDS`), в дополнение к общему каналу уведомлений.
- Упрощены уведомления о новом реферале (`bot/app/services/referral_service.py`): удален текст с обещанием бонусов за пополнение как для нового пользователя, так и для пригласившего.
- Добавлена новая настройка `SKIP_LANGUAGE_SELECTION_AT_START` (по умолчанию `True`). Теперь выбор языка при регистрации по умолчанию пропускается (язык определяется автоматически по профилю Telegram), но функция смены языка в меню продолжает работать (параметр `LANGUAGE_SELECTION_ENABLED` должен быть включен).
- Обновлен шаблон пригласительного сообщения (`bot/app/handlers/referral.py`): убрано прямое упоминание VPN и бонусов за пополнение. Исправлено форматирование при нажатии кнопки «Поделиться»: теперь сообщение отправляется без префикса с именем бота и без лишних HTML-тегов (Premium эмодзи), что делает текст чистым и готовым к пересылке.
- Обновлены файлы локализации (`bot/locales/ru.json` и `bot/app/localization/locales/ru.json`): значения ключей `REFERRAL_INVITE_*` теперь соответствуют новому варианту текста без упоминания VPN, что гарантирует использование актуального текста даже при наличии старых данных в файлах перевода.
- В класс `Texts` (`bot/app/localization/texts.py`) добавлен метод `t_raw` для получения текста без автоматической замены эмодзи на Premium-теги.
- **БЕЗОПАСНОСТЬ:** Удален скомпрометированный API токен CryptoBot из файла `bot/.env.example`.
- Обновлен интерфейс реферальной программы (`bot/app/handlers/referral.py`): теперь строки с бонусами и доходами (всего/за месяц) автоматически скрываются, если они равны нулю. Текст «Заработано всего» изменен на «Вам начислено на баланс». Заголовок «Как работают награды» изменен на «Ваши бонусы от сервиса», и теперь весь этот раздел (включая заголовок и проценты) полностью скрывается, если все значения равны нулю. Удалена статистика «Сделали первое пополнение», а призыв в конце изменен на «📢 Приглашайте друзей и получай бонусы!».
